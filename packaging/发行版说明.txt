CardVault 2.2.1 · Windows 64 位发行版
===================================

使用方法
1. 运行 CardVault-2.2.1-Setup-x64.exe 安装。
2. 从桌面或开始菜单打开 CardVault。
   也可解压目录发行包，保留完整目录后双击 CardVault.exe。
3. 选择源存储卡和目标目录，开始备份。

安装包已包含 Python、PySide6 和需要的库，不用预装 Python、pip 或任何 Python 库。
安装目录包含 CardVault.exe 和 _internal 依赖目录（DLL、Python 运行时和 Qt 资源）。
不要只复制 EXE 或删除 _internal。无需 BAT 启动。卸载保留任务记录。
适用 Windows 10/11 64 位；不支持 Windows 7 或 32 位系统。

高级功能：右上角“更多”及“拷贝选项”。
报告：任务历史 → 详情与日志 → 导出报告。

任务与设置
发行版默认保存至：%LOCALAPPDATA%\CardVault
可在资源管理器地址栏粘贴该路径。
升级或卸载程序 不会清空任务记录。

从源码版迁移旧记录（可选）
先退出两个版本，再将源码目录 data 中的任务 JSON、JSONL、preferences.json
和 reports 文件夹复制到上述目录。不要复制 .instance.lock 或 .session-url。
为避免同一任务同时写入，不要同时运行两个版本进行相同的备份。

程序未使用代码签名证书。不会自动申请管理员权限，不修改系统目录权限。
对无法写入的目标，会在复制前报告错误。

当前发行包不包含任何用户任务记录、源卡素材或测试素材。
源卡只读；已有目标文件只有选择“覆盖”并确认时才被替换。

构建核验
发布时执行全部回归测试，并在清除 Python/PySide 环境路径的进程中执行 EXE 自检。
这不等同于所有 Windows 硬件的实机验证；原 I: 盘故障仍需重新连接后复测。

诊断命令（可选）
CardVault.exe --self-test "D:\检查结果\self-test.json"
诊断使用独立临时素材进行双目标拷贝并生成结果，不会拷贝真实存储卡。

2.1 新功能
更多 → 设置：并发拷贝 1–8 个文件（默认 3，新任务生效），以及简体中文、繁体中文、英语、日语。
首次启动按系统时区选择语言，手动设置优先，语言修改下次启动生效。

2.2 新功能
设置中可选择逐份或集中校验，调整软件字体与主题色。报告突出成功和失败数。
更新选项卡可拖入更新的 CardVault Setup 安装包，保存至 update 后安装、替换当前目录并重启。
更新前自动安全暂停任务。更新日志位于 update 文件夹。2.1 用户需先手动安装 2.2。
